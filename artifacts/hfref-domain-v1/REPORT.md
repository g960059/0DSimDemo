# HFrEF：LV収縮能低下デモの範囲・操作経路検証

2026-09-09。研究worktree `codex/hfref-domain-experiment-v1`。
公開済みStandard72のartifact・baseline・評価記録は変更していない。
この研究候補をStandard73として固定・公開したものではない。

## 採択した範囲

GPT-6 Astra xhighとClaude Fable 5.1 xhighへ一括で独立レビューを依頼し、
両者から条件付き賛成を得た。1/2 gateはAstraの条件に従って満たす。

- LV自由壁と共有中隔の能動張力倍率のみ、下限を0.75から0.25へ拡張。
  上限1.33は維持。RV自由壁・心房・全心室一括操作の範囲は変更しない。
- workbenchの「LV収縮性」はLVFWとSEPを一つのtransactionで同値に設定する。
  個別壁の操作も残す。異なる倍率はmixedとし、平均値で置き換えない。
- 変えるのは能動張力の振幅であり、EF、Ees、viabilityの直接指定ではない。
  Caの時間特性、受動特性、形状、弁、TBV、血管設定はこの候補では変えない。
- baselineから手動で到達できること、同じモデル所有のcheckpointでpresetを
  起動できること、既存の解析・Surface項目を引き継ぐことを採択条件とする。

範囲端での4.8秒の計算継続を検証したが、全Cartesian空間での定常性・
生理的妥当性を保証するものではない。以後の症例ごとに評価が必要である。

## 探索と候補選択

先行するStandard72の現行範囲内の39条件ではHFrEF候補は得られなかった。
LVFW+SEP=0.75の最小EFは45.7%で、冷起動と細かい時間刻みでも再確認された。
これは限定した探索であり、モデル全体の表現不可能性の証明ではない。

workbench刻みから外れ、設定を増やす理由にも乏しいため採用しなかった。

## 添付の虚血性心疾患・PV図を踏まえた再評価（2026-09-09）

以下は原著と実装を照合した再評価・提案であり、新しいgateの採択記録ではない。
この追記ではregistryの範囲、exact model、Surface、preset、過去の結果を変更していない。

### 症例の名前と再現する対象

HFrEFはHF患者のLVEFによる分類であり、慢性期や虚血性病因に限定されない。
またEF低下だけでは臨床的なHF診断にならず、症状・徴候などはこの0Dモデルの
出力だけでは判定できない。[2022 AHA/ACC/HFSA guideline, §2 / Table 4](https://www.ahajournals.org/doi/abs/10.1161/cir.0000000000001063)

今回の0.35候補は「形状の参照値を固定した、左室優位の能動張力低下と二次的な
循環変化」の機序対照として残す。慢性HFrEFの機能的な一状態と矛盾するとまでは
言えないが、慢性拡大型HFrEFの代表性や構造リモデリングは検証していない。
周期定常化したことは、数か月の病歴や組織の再構築を表現したことではない。
LVFW+SEPの振幅を一様に下げる操作は、梗塞量・viability・局所冠虚血の指定でもない。

最初の疾患presetとしては、**慢性HFrEF（左室拡大型、左室収縮能低下を主体）**を
別途評価することを推奨する。これはHFrEFの全例に拡大を要求する提案ではなく、
今回代表させる表現型の選択である。急性局所虚血・梗塞後瘢痕・急性増悪は混ぜない。

### 原著で確認できた点と、図から一般化できない点

- **局所虚血と全体の張力低下は同じ操作ではない。** Sunagawa 1983は摘出灌流犬心6例。
  生理的圧域の局所虚血ではESPVRの右方移動が主体で、低い圧域では傾きも変わった。
  一律の「虚血ならEesが低下する」条件にはできない。
  [原著抄録・実験条件](https://pubmed.ncbi.nlm.nih.gov/6825214/)
- **慢性梗塞の引用図は、慢性HFrEF全体の基準値ではない。** van Hout 2013の著者収録版
  （de Jong学位論文第12章、pp.266–277、特にTable 1 / Figure 1 / Table 5）を確認した。
  麻酔・開胸下のブタ11頭、LAD閉塞後8週で、ASのESPVR勾配は有意に低下せず、V0が右方移動。
  EFは低下したがEDV変化は有意ではない。主目的は測定法比較で、梗塞後の容積計測に
  方法依存の差もあった。図の右方移動を、ヒトの必須EDVI下限、受動EDPVRの変化量、
  PVA増加率の根拠にしない。
  [論文 DOI](https://doi.org/10.1113/expphysiol.2013.074179) / [著者収録版](https://repub.eur.nl/pub/76942/140926_Jong-Renate-de.pdf)
- **Pak 1996の引用を題名だけで誤引用と判断してはいけない。** 主題はHCMだが、
  正常LV機能11例・高血圧性肥大13例・DCM9例を比較群として含む。IVC閉塞による
  EDPVRと一拍内の充満PV軌跡を区別しており、後者の平坦さだけで受動硬さを断定しない
  ための重要な資料である。本文のDCM数値・図の完全な照合は未了で、数値gateに転記しない。
  [原著抄録](https://pubmed.ncbi.nlm.nih.gov/8964117/)
- **充満圧の上昇と受動材料の硬化は別である。** Kass 1990のPTCA患者10例では、
  安静PV点は上方移動しても、IVC閉塞で比べた拡張末期関係にはほぼ差がなく、
  RV・心膜負荷の影響が指摘されている。絶対圧、経壁圧、残存能動張力を分ける。
  [原著抄録](https://pubmed.ncbi.nlm.nih.gov/2297855/)
- **添付の「弛緩が遅くなるとτが低下」は、通常の圧下降時定数の定義と逆。**
  P(t)=P∞+(P0−P∞)exp(−t/τ)なら遅い減衰は大きいτに対応する。
  ヒトPCI研究25例でも冠閉塞後のτ延長が報告されている。ただし、これは急性虚血の
  方向性を示すもので、慢性HFrEFの必須数値範囲を与えるものではない。
  [ヒト冠閉塞研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3331587/)

### PVAについての数理的な整理

以下は文献の正常値ではなく、面積の定義からの考察である。
外的仕事SWはPV閉曲線の面積であり、単なる容積座標の平行移動では変わらない。
PV loop、ESPVR、EDPVR、容積原点が同じ量だけ平行移動する思考実験なら、
PEとPVAも変わらない。したがって「右方移動したから必ずPVAが増える」は成立しない。

拡張期圧を無視し、線形ESPVRを仮定すれば、PE≈P_es²/(2E_es)。同じP_esで
E_esが低下すればPEは増えるが、実際にはP_es、V0、EDPVR、SVも変わる。
PVA=SW+PE、外的仕事、心筋の酸素消費量は同一量ではない。
Shinke 1999でもHR低下による右方移動・SW増加と、PVAの有意変化なしが併存した。
対象は旧梗塞/DCMのLV機能低下14例で全例が現在のHFrEF定義ではない点にも注意する。
[Shinke 1999, Table 3 / Figure 2](https://www.jstage.jst.go.jp/article/jcj/63/12/63_12_957/_pdf/-char/en)

### 現候補の解釈で修正する点

- mean Ao node 72.85、最高/最低84.16/62.14 mmHg、平均LA20.70、LV充満終了時圧26.08
  （経壁23.90）という組合せは、低血圧・左側充満圧上昇に寄った候補である。
  「標準的な安定慢性HFrEF」全体を代表するものではない。血圧・CIだけでショックとも
  判定しない。mean LAはPAWPそのものではなく、Ao nodeは上腕血圧そのものでもない。
- EDVI94.58が推奨100–140に届かないことだけでは不適切といえない。その下限は
  原著の診断境界ではなく、今回の構成上の選択である。重要なのは、現在のEDV増加が
  参照形状の変化ではなく同じ壁特性下の負荷・状態変化から生じていることである。
- EF・EDVI・CIは独立ではない。HR70、逆流・シャントなしなら
  CI≈0.07×EF×EDVI。EF34%、CI2.5ならEDVI約105 mL/m²で足りる。
  EF30%、EDVI140ならCI2.94となり、現行preferred CIの上限2.8と両立しない。
  各目標箱を独立した「典型性の証拠」と数えない。
- LVのICTは89→42 ms、Teiは0.702→0.483。低い大動脈圧と高い充満圧によって
  弁を開くまでの圧差・開閉時刻も変わるため、これを収縮機能の改善とは解釈しない。
  負荷による説明は仮説であり、位相を合わせた弁イベントと圧上昇を確認して検証する。
- Weiss τは32.04→50.41 msだが、候補のfit窓は20.6 msと短い。非ゼロ漸近圧の
  Glantz τは品質不良で未確定。Weissの値をMoriwakiの非ゼロ漸近圧τ88±23 msと
  同じ尺度として比較しない。Moriwakiは治療後HFrEF10例、CI2.6±0.4・PAWP12±8であり、
  高充満圧がHFrEFの必須条件でないこともわかる。
  [原著の方法・Table 2](https://onlinelibrary.wiley.com/doi/full/10.1002/ehf2.13682)
- RVFW入力は固定でもRVEF56.92→43.03%、RV Tei0.357→0.725となる。
  共有中隔・肺循環負荷の変化を含むので「RVは正常のまま」とは記載しない。
- workbenchの収縮期表示は定常負荷群の圧包絡、拡張期表示は最大容積点の負荷応答。
  カテーテルIVC閉塞のEes/V0や、完全弛緩した受動構成則とは異なる。現在の表示から
  文献の線形Ees・EDPVR・PVAに対する厳密な合否を直接作らない。

現在のEF優先の選抜だけでは、低い血圧・高い充満圧でEF目標を達成する候補を
拾いやすい。まず選んだ表現型の血行動態・形状・収縮指標の同時成立を確認し、
その中で操作数やbaselineからの変更量が小さい候補を選ぶ方がよい。

既存registryで、対象集団→測定方法→観測値→設計した範囲、という来歴を保つ。

### 次の検証は小さな因子比較に限定する

1. 現候補を固定形状の機序対照として保存し、慢性拡大型presetの表現型条件を先に固める。
2. baseline / 張力低下のみ / 参照形状変更のみ / 両者、の比較から始める。
   TBVだけでEDVIを押し上げず、同じ充満圧で受け入れられる容積と残存拍出を確認する。
3. 形状を調べるなら、既存TriSegの参照中壁面積と心筋壁体積を第一候補とする。
   これらはすでに構成パラメータだが、現行の症例用可変入力ではない。
   V0やPV loopを描画だけでずらす操作は使わない。参照面積は線維伸長を通して
   能動・受動の両方に効くため、単なる「EDPVR横移動knob」とは扱わない。
   壁体積、材料の硬さ、伸長、外圧・中隔の整合性を保ち、必要性が見えた最小の入力だけ露出する。
4. Ca/Land速度定数は初手で増やさない。弛緩の方法適合性・残存張力の検証が不足を示す
   場合だけ次の因子とする。成長・リモデリングの長期時間発展を解く新しいODEは不要で、
   慢性状態に対応する静的な構成値から検討できる。
5. 新しい範囲・露出・永続gateはまとめてAstra xhigh / Fable 5.1 xhighの1/2 reviewにかける。
   既存の張力下限拡張への承認を、形状変更や新gateへの承認として使わない。
   形状が変わる場合はcheckpointの整合性を確認し、以前の状態を無条件に流用しない。

## 慢性左室拡大型の説明軸とreference登録（2026-09-09）

### この一例で何を説明するか

τ延長や高い充満圧は出発点の例であり、症例像をその二項目へ限定しない。
この例の主題を、**大きくなった左室が収縮後にも多くの血液を残し、送り出す割合は低いが、
安静時の正味拍出はある程度保たれている状態**とする。さらに、圧発生、充満、肺循環・右心、
外的仕事を関連づけて説明する。これは慢性期の左室拡大型を選んだ教育用の構成例であって、
全HFrEFの平均患者でも、局所AMIの急性変化でも、拡大に至る時間経過のモデルでもない。

所見が患者の全員にないことは、症例の特徴として採用しない理由にはならない。
ただし、別々の論文で多い所見を全部盛りにすると、実在性が不明な複合像になる。
そのため、次の三つの**役割**を使い分ける。読者を三階層へ分類するUIではない。

| 説明軸 | 今回の役割 | 誤解を避けるために残す情報 |
|---|---|---|
| 大きなLV、低EF、多い収縮後残存容積 | 症例の中心。EFとEDVIをscreenし、ESVIも記録 | EDVIとESVIは弁閉鎖時の値。全HFrEFに拡大を要求しない |
| 低EFでもある程度保たれる正味拍出 | 積極的に示す目標 | CI・SVI・EF・容積の依存関係。低EFとショックは同義でない |
| 圧発生と循環負荷 | 観測して説明 | ±dP/dt、ICT/ET/Tei、原波形。Ees未測定をEFから補わない |
| ゆっくりした圧低下、高めの左心充満圧 | この一例で伴わせたい目標。疾患の必要条件ではない | Weiss/Glantzの方法差、fit窓、mean LAとLV充満末期圧、E/A |
| 拡大した形状と受け入れ容積 | 機序確認が必要な説明軸 | 同じ経壁圧での受動比較。形状変更と材料の硬さを区別 |
| 肺循環と右心への影響 | 出た結果を観測して説明 | PAP、RA圧、RVEF、RV容積。一次性右心障害や肺血管病変を強制しない |
| 外的仕事とエネルギー評価 | 測定済みと未測定を分けて説明 | 実PV線積分のSW、formal PVA、MVO₂は別物 |

説明したい内容を`expectedFinding`、実測を`observations`、残る注意を`limitation`として
分離した。設計上の文章だけで「この候補で実現した」と判定・記事化しない。
EF低下、MR、肺高血圧、右心不全、拘束型流入、τ延長を一括した必須セットにはしていない。
MRやAF、局所梗塞などを加えた別の構成例まで、今回の一例で代表させない。
