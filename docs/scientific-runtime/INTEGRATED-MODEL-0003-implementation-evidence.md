asserts the stated implementation property in this branch. It does not promote
construction data to independent evidence. Numerical verification,

device certification, physiological release readiness, or authorization to
register an integrated `SimulationReleaseRef`.

## 3. Current release conclusion

The branch has a coherent numerical substrate for coronary V3, stateful MCS,
static replay, generated signed-history sinus/flutter with AV recovery, a
standalone stationary seeded AF atrial source with exact random-state resume,
and Transaction V3 composed-rhythm ownership as the sole live calcium source.
The cold all-device-off V3 canonical run now establishes full accepted-state P1
at cycle 70 with exact event lineage, conservation and checkpoint continuation.
Its raw graph is numerically smooth, but the healthy-reference screen remains
3/6: EDVi, ESVi and PASP fail the unchanged gates. The base release fails the
same three categories, so this is inherited review work with small integrated
deltas, not a new categorical failure and not a reason to retune by inspection.
The expanded pulmonary audit now localizes the broad closed-valve PA rebound
to `45.65 mL` of reverse `PA_PArt` exchange in a very lightly damped proximal
RLC mode. That is a structural pulmonary-load review blocker: mean PVR or TBV
adjustment is not an adequate correction, and no R/L/C default is changed in
this branch.

The earlier active-HMII V2 fixed-horizon and checkpoint-started local-refinement
artifacts remain numerical/transcription evidence only; their substantial
reverse-flow and above-domain residence still require matched mock-loop
protocols. Coronary pressure-step V1 retains its metric-definition failure and
V2 passes its separately declared direction-independent numerical comparator.
The fixed-tone structural-CMD V1 direction failure is likewise retained. Its
active-rest-to-hyperemia V2 companion recovers decreasing reserve across the
structural-resistance axis with excellent cross-dt agreement, but still fails
the predeclared rest-convergence/target aggregate gate. The modeled AoV event
planned for IABP integration is now limited to forward-flow cessation; the
quasi-steady valve cannot support an independently validated anatomical
leaflet-closure claim. These findings are kept as mixed pass/fail evidence
rather than normalized into physiology.

An integrated release remains blocked until the open physiological,
device-specific, rhythm-generation, interaction, duration, Worker, registry,
and UI/catalog gates above are closed with separately classified evidence.
