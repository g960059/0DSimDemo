# Article authoring

記事・図・埋め込み実験の企画、執筆、改稿に適用。変更に関係する規則・参照だけ使う。

- **水準**：分野の基礎知識を前提に、専門家が機序を説明し直せる深さを保つ。初学者には定義・前提知識への導線を補う。読後に条件変更の結果を予測し、根拠を説明できる内容とする。
- **調査**：新規執筆・大幅改稿前に、仮の問いから論文・類似書籍・講義資料を横断し、主要な説明体系・異論・実験例を把握する。採用する論点の根拠・成立条件を原典で確認した段階で、論旨・構成を決めて執筆へ進む。
- **論証**：用語・増減則・比喩で終えず、必要な因果・導出・比較条件を示す。記号・単位・成立条件を定義し、式・図・観測を結ぶ。構成は問いに合わせて選ぶ。
- **本文**：必要な条件のもとで言い切る。補足、反復する否定、例外・方法の詳細は注釈へ。結論を変える前提・未確定性は本文に残す。
- **文章**：一段落一論点。観察・予測と説明・再検討で緩急をつける。進行実況、架空の逡巡、重複要約を削り、理解に必要な論理は省かない。
- **根拠**：実測・一次資料を優先し、主張と根拠を照合する。観測・推定・仮定を区別する。参考資料も検証し、モデル構築に使った資料や外見の一致を独立検証と扱わない。
- **図**：問いに応じて実測図・データ由来図・概念図を選び、由来を示す。自作のデータ由来図は再現可能にする。図番号・タイトル・説明を付け、本文から参照する。目的に不要な数値・重複表示を削り、帰属・利用条件は控えめに添える。生成画像は個別依頼時のみ。
- **実験**：操作・固定条件・観察対象を絞り、比較・予測の検証に使う。既存の条件・解析を再利用し、読書を妨げない表示を選ぶ。
- **機能改善**：制作中に有用な出力・グラフ・設定・表示・parameters/knobsを積極提案する。用途、既存手段の不足、再利用性、科学的妥当性、UI負担、検証計画を示し、提案者と別のCodex Astra 6（xhigh）が独立審査する。通過した範囲は追加承認なしで実装・検証する。数式・モデル変更への拡大は、責務分担と科学的検証を含め再審査する。
- **参照**：引用と注釈は別系列の上付き番号、末尾一覧、戻りリンク。出典をカード化せず、既存の参照機構を使う。
- **確認**：レビュー・推敲後に論旨・式・条件・引用の意味を再確認する。変更した表示・操作を実際のreaderで確かめる。

必要時の参照：文章の緩急・冗長さは利用可能な `cognitive-rhythm-writing` skill（本書の科学・編集原則を優先）、保存・埋め込みは [authoring API](../tools/authoring/README.md)、fitting・実測比較は [calibration](scientific-runtime/CALIBRATION-0001-identifiability-first-fitting.md)。操作仕様・式は転記せず、現行API・コードから取得する。
